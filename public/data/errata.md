# 原书勘误表（Errata）

> **真源就是本文件**（`docs/errata.md`）。站内页面 `#/errata` 渲染的是它的副本 `public/data/errata.md`，
> 由 `npm run build:index` 自动同步 —— 只改这一份，不要改副本。

## 0. 处理原则

- **不轻易改动原书语义**：只有「原样不可编译」「结果恒错」「题面与书末答案自相矛盾」三种情况才修，
  修完必须在题目 `explanation` 里写明「原书印作什么、为什么改、拿什么证据改」。
- **判分口径以实机为准**：`npm run judge:verify` 在 Godbolt 上真编译真执行，stdout 与逐请求耗时存档进
  `public/data/problems/verification-report.json`；与书末答案冲突时以实机输出为准并记录差异。
- **符号形态本身就是考点的，照录不归一**（见第 4 节）。

## 4. 照录不改的印刷特征（符号形态本身就是考点）

- 长横「一」不归一为 ASCII 减号：题2.5 / 题2.6 / 题2.7 / 题10.88（常量合法性判断、转义字符、运算符辨认）
- 星号空隙 `x* cnum`、`( * p)`，以及 `main( )` 括号内空格：只是排版形态，token 序列不变，照录
- 上标 / 根号 / 分式一律线性化，线性化后的形式在题目详解里写明

## 5. 复核方法（任何人可复现）

```bash
npm run build:index     # 把本文件同步到 public/data/errata.md
npm run verify:data     # 数据闸门：error 必须为 0
npm run judge:verify    # 实机复验代码题（Godbolt，严格串行）
```

站内入口：页脚「📕 原书勘误表」，或直接访问 `#/errata`。上表每条题号都可点进对应题目页核对详解原文。
