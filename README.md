## 用 Windows 桌面客户端开始（三步）

### 第 1 步：解压

右键 `C_practice_项目包.zip` → **全部解压缩** → 得到 `C-practice` 文件夹。

建议放在简单路径，如 `D:\C-practice` 或 `C:\Users\你的名字\Documents\C-practice`。

> ⚠️ 解压后必须是这样的结构（`AGENTS.md` 和 `00_任务书.md` 在同一层）：
> ```
> C-practice/
> ├── AGENTS.md        ← 项目约定
> ├── 00_任务书.md
> ├── 01_知识大纲_C语言.md
> ├── ...
> └── schema/

> 如果多了一层嵌套（如 `C-practice\C-practice\`），把内层文件移出来。

### 第 2 步：用 Codex 客户端打开

- 打开 Codex 桌面客户端
- 找 **Open Project** / **打开项目** / **打开文件夹**
- 选中 **`C-practice` 这一层文件夹本身**，不要选它的父目录

### 第 3 步：新建对话，发第一轮指令

复制下面的话发过去（详见文末「第一轮指令」）：

```

确认无误后，按任务书第六节输出技术方案。
本轮不要创建任何文件。
```

**等它出方案、你确认后，再让它写代码。**

## 主力题型（占 80%）

| 题型 | 说明 | 自动判分 |
|---|---|---|
| 程序填空 | 可编译代码中挖空，补全后跑测试 | ✅ |
| 程序改错 | 植入 2-3 个典型错误 | ✅ |
| 程序阅读写结果 | 写真实运行结果 | ✅ |
| 编程题 | ≥4 组测试用例 | ✅ |

辅助题型：概念选择、判断、概念填空、代码排序、复杂度分析、简答、匹配。

> **现实注解（2026-09-14 终验）**：上表设定的「占 80%」是目标值，不是现状。
> 主力四型实际合计 **1084 / 2074 = 52.3%**（程序阅读写结果 514、程序填空 354、编程题 162、程序改错 54），
> 其余为概念选择 644、概念填空 261、判断 53、简答 23、复杂度 9。
> 这是**主动放弃项**而非疏漏：存量语料以概念题为主，强行改型会切断题目与教材知识点的既有对应关系，
> 性价比低于「把已有题全部实机验证」。取舍依据见 `docs/网站完成报告.md` 第八节「已知缺口」。

## 关于教材正文

9 份 PDF 检测结果分三类：

**A 类·正文可用**（已提取目录与关键内容）
- 试题汇编 328 页（系统解析出目录 + 前 2 章原题全文）
- 严蔚敏数据结构 274 页（165 条目录 + 第1章正文）
- 朱战立数据结构 321 页（11 章目录 + 第1章正文）

**B 类·正文有 OCR 损伤**（只提取目录）
- 谭浩强 C程序设计 395 页：纯扫描 → 目录 208 条
- 大话数据结构 464 页：ABBYY 劣质 OCR → 目录 111 条
- C Primer Plus 1482 页：中文 CID 乱码，不可恢复 → 目录 541 条

**C 类·重复或残本**
- `C Primer Plus第6版` 与 `习题解答` 是同一文件（字节数相同）
- `数据结构C语言版第2版` 与 `数据结构++C语言版++第2版` 是同一文件
- `30352985.pdf` 17 页残本，已被 328 页完本取代

**核心判断**：B 类正文代码有 OCR 损伤
（`=`→`)`、`L`→`1`、`||`→`11`），喂给 Codex 会生成错误答案。
故不提供损坏正文，改为「大纲定章节 + Codex 自主写正确代码」。

## ⚠️ 教材代码的两大坑

### 坑 1：严蔚敏教材是类C伪码，不能编译
含 `&` 引用、`new`/`delete`、`cin`/`cout`。详见 `05`。
**出题一律生成标准 C。**

### 坑 2：大话数据结构 PDF 的 OCR 代码是错的
`typedef stru'ot DulNode`（应为 `typedef struct DulNode`）、
`ElemType dat事J`（应为 `ElemType data;`）。
**不要从 PDF 正文抄代码。**
