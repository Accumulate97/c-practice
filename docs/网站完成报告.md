## 五、判分与验证体系

- 后端：Compiler Explorer 公共 API，POST https://godbolt.org/api/compiler/cg132/compile，免 API Key，浏览器直连
- 请求契约：executorRequest: true 与 filters.execute: true 双开关缺一不可；executeParameters 必须位于 options 层级下；编译参数 -std=c99 -Wall -Wextra -O0
- 响应解析：结构扁平、无 execResult 包裹层（禁止 execResult 兜底）；stdout 规范化 (j.stdout||[]).map(o=>o.text).join('\n')；断言 didExecute === true && truncated === false
- 判分顺序：buildResult.code != 0 → compile-error；timedOut → timeout；再看退出码；最后看输出截断。顶层 code = -1 有双重含义（编译失败 / 运行时被信号杀死），必须靠 buildResult 区分
- 超时与并发：软超时 25 s（> Godbolt 自身约 20 s 执行时限，避免两个 20 s 相撞把「运行超时」误判成「后端不可用」）；Godbolt 是排队不是限流且并发越高吞吐越低，故多组测试用例一律严格串行
- 降级模式：后端不可用时读构建期预存 stdout 供学生自评，不计正确率、不置 verified、绝不伪造「通过」
- 抽象层：src/judge/ 的 JudgeBackend，BACKENDS 注册表 + getBackend() + registerBackend()，新增后端按契约补一个适配器即可
- 容灾（本轮任务 3，ADR-0002）：src/judge/failover.ts 的 createFailoverBackend 把「主 + N 备」包成仍满足 JudgeBackend 契约的单一对象；默认链 godbolt(cg132) → godbolt:cg142 → godbolt:cg131 → 全灭才落 client 既有降级自评。只有 retryable 的传输层错误（5xx / 网络 / 坏 JSON / 缺 didExecute / 429）才换级；25 s 软超时 abort 与 401/403 立即抛出绝不换级（否则一次超时 25 s 会变 75 s）；编译错误与运行崩溃是 ExecutionResult 事实，不触发切换。两道闸：健康记忆冷却 60 s（全冷却时仍按原序试一遍，不永久拉黑）+ 单次 execute 墙钟预算 30 s。链 id 沿用 tiers[0].id='godbolt'，client 的缓存键 / 跨标签页锁 / JudgeLab 显示名零改动，学生无感。VITE_JUDGE_FAILOVER=off 可整体关闭，行为回到改动前
- verified 纪律：只允许 npm run judge:verify 实机编译 + 执行 + 比对后置位，禁止手工置 true；verify-data.ts 用 VERIFIED-NO-PROOF 反查报告；后端 5xx / 网络失败判为「未判定」而非「失败」，last_known_good 证据只增不减
- 证据存档 public/data/problems/verification-report.json（本轮任务 2 全量复跑后刷新，generated_at 2026-09-14T06:33:10Z）：2157 次请求 / 总墙钟 1305 s / 均值 605 ms / serial_only: true / cg132 / -std=c99 -Wall -Wextra（执行 -O0）；1078 道代码题全部 PASS、inconclusive_this_run = 0，last_known_good 1079 条（只增不减）

### 13.1 任务 1 · 变式题质量扫描 → `docs/变式题质量报告.md`

### 13.3 任务 3 · Godbolt 备用后端 → `docs/adr/0002-judge-failover.md`

**任务书点名的两个第三方，2026-09-14 实测都不可用**（取证 `npm run probe:backends`，原始响应存档 `tmp/backend-probe.json`）：

| 候选 | 端点 | 实测结果 | 结论 |
|---|---|---|---|
| Piston | `POST https://emkc.org/api/v2/piston/execute` | **HTTP 401** | 2026-02-15 起白名单制，匿名请求一律拒；与 ADR-0001 复测一致，**未恢复** |
| Wandbox | `POST https://wandbox.org/api/compile.json` | **HTTP 500**（`Failed to get uid`） | 沙箱侧起不来；ADR-0001 记的是三次 504，**仍不可用** |
| Godbolt `cg132`（GCC 13.2） | `POST /api/compiler/cg132/compile` | **200 / didExecute=true**，929 ms | 现役主级 |
| Godbolt `cg142`（GCC 14.2） | 同上 | **200 / didExecute=true**，991 ms | 备用一级 |
| Godbolt `cg131`（GCC 13.1） | 同上 | **200 / didExecute=true**，1086 ms | 备用二级 |

也就是说：**此刻不存在任何可被纯静态站浏览器直连的第二厂商**。剩下的三个选项里，
自建/租用编译服务违反硬约束 1「纯静态、无后端」（且本项目要开源，不能依赖个人实例）；
需要 API key 的服务（judge0 等）key 只能打进 bundle，等于公开泄露。
故**容灾只能在 Godbolt 内部做同厂多版本冗余**（`src/judge/failover.ts::createFailoverBackend`）：

- 默认链 `godbolt(cg132) → godbolt:cg142 → godbolt:cg131`，**全灭才落 client 既有降级自评**（不伪造通过）。
- 只有 retryable 的传输层错误（5xx / 网络 / 坏 JSON / 缺 `didExecute` / 429）才换级；
  25 s 软超时 abort 与 401/403 **立即抛出、绝不换级重跑**（否则一次超时 25 s 会变 75 s）；
  编译错误 / 运行崩溃是 `ExecutionResult` 事实，不触发切换。
- 两道闸：健康记忆冷却 60 s（全冷却时仍按原序试一遍，不会永久拉黑）+ 单次 execute 墙钟预算 30 s。
- **判分口径跨级完全一致**：三级同一个 `GodboltAdapter`，`-std=c99 -Wall -Wextra`（执行 `-O0`）、
  `executorRequest` 与 `filters.execute` 双开关、严格串行队列、软超时 25 s 逐项相同；
  梯队参数取最保守一档（并发取最小、间隔取最大、超时取最长）。
- **用户无感**：链 id 沿用 `tiers[0].id = 'godbolt'`，client 的缓存键 / 跨标签页锁 / JudgeLab 显示名零改动。
- 明确不做：`getBackendFor()`（用户显式选编译器）不挂梯队 —— 不拿别的编译器冒充用户的选择；
  libm 支路 `cicc191` 不混入 C 梯队。
- 开关：`VITE_JUDGE_FAILOVER=off` 可整体关闭，行为回到改动前；`.env.example` 写明开关与「为什么不接第三方」的实测依据。
- 验收 `npm run acceptance:failover`：**14 PASS / 0 SKIP / 0 FAIL**（离线 10 项故障注入 0 真实请求 + 在线 4 项真跑），
  含「主级注入 502 → cg142 接手 → 学生侧 `accepted`」的真实端到端，
  以及跨级口径一致（scanf 读 stdin=100 → 338350，两级同结果）。
  **主链路未受影响**：默认后端真跑 `state=accepted`，execTime 36 ms。

### 13.4 任务 4 · 首访引导 + 移动端 + 加载体验（commit `6d54554`）

- **移动端**（`useMobileEditor`，真机视角而非「375px 不溢出」）：
  iOS 聚焦「字号 < 16px」的可编辑元素会强制整页放大到 ~150% 且失焦不缩回 →
  触屏（`pointer: coarse`）下编辑器 13→16px、行高 20→26px、行号 12→13px，表单控件一律 16px
  （必须 `!important`：`text-sm` 是类选择器，元素选择器压不住）。
  软键盘遮挡：iOS 键盘弹出只缩 `visualViewport` 不缩 layout viewport，而 CodeMirror 自带的 `scrollIntoView`
  只看 layout viewport → 监听 `visualViewport` 的 resize/scroll，光标落到可视区外时滚**页面**（滚编辑器内部顶不开键盘）。
  手机上没有物理键盘（`Mod-Enter` 等于不存在）→ 底部留 6rem 白，最后一行也能顶到键盘上方。
  实现走「宿主 div 上的 CSS 自定义属性」而不是再造一份 `EditorView.theme`：
  CM 的样式模块运行时注入 head、同特异度必然覆盖我们；且旋转屏幕时不必销毁重建编辑器（重建会丢 undo 栈）。
- **3D 馆加载与低配降级**：`LoadingBar` **不编百分比**（浏览器不暴露动态 import 的下载进度，
  画个假「60%」卡在那里比什么都不显示更让人以为站点挂了），只如实表达「在加载」+「已经等了多久」，

### 13.8 本轮踩坑（续接者必读，接第十节）

10. **播种 localStorage 之后必须整页 `reload()`**：只改 hash 不会重跑 zustand persist 的水合，
    store 里的 `records` 还是空的。`acceptance:onboard`「老用户不弹引导」这条用例最初就是这么假挂的
    （断言本身没错，是前提没建立）。现在改成：播种 → `reload()` → 先断言首页「做过的题」= 2 → 再断言不弹。
11. **别用「DOM 上有没有 `onxxx` 属性」验 React 事件**：合成事件全挂在根节点，元素上永远查不到内联处理器，
    那种断言恒真、是假测试。要验「hover 才预取」，就直接数网络请求（`page.on('request')`）。
12. **CSS 装饰动画用 `transform` 会让元素盒子跑出视口**：即使父级 `overflow:hidden` 裁掉了、
    `document.scrollWidth` 也不变宽，逐元素量 `getBoundingClientRect` 的探针照样报。
    窄屏越界检查有「scrollWidth 口径」与「逐元素盒子口径」两种，本站 `a11y:probe` 是后者（更严），
    写装饰性动画时要按后者想 —— 用 `background-position` 滑动可以两全。
13. **意图预取不能用空闲预取**：`requestIdleCallback` 里 import three 会给每个路过 3D 列表页的人下 885 KB，
    直接撞掉既有验收的「列表页零 three 体积」不变量。用 hover / focus 表达意图，收益等价、代价近零。
14. **低配探测不能否决用户的明确点击**：`pref === 'solid'` 是「仍要看 3D」，启发式（核数 / 内存 / 省流 / 动效偏好）
    只该参与 auto 模式，否则那个按钮就成了死的。降级还必须**说明理由**并**留出口**。
15. **补丁脚本必须幂等**：本轮有编辑工具会把同一次调用执行两遍，锚点替换式补丁第二遍会再替换一次 → 内容重复、
    文件损坏（`useStageEnv.ts`、`Viz3DListPage.tsx` 各中一次，靠 `git checkout --` 还原后重放）。
    一律写成 `if (src.includes(marker)) skip`，并且**marker 必须是插入内容里真实出现的子串**
    （`const worthWarming` 匹配不到实际插入的 `const [worthWarming]`，就是这么漏的），改完跑一遍重复计数校验。
